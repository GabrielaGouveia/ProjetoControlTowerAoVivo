# 🚀 Projeto Control Tower ao Vivo

Projeto desenvolvido durante um workshop prático de Dados e Inteligência Artificial, com foco na exploração de ferramentas e tecnologias utilizadas no mercado para construção de soluções orientadas a dados.

A iniciativa faz parte da minha jornada de aprofundamento em Engenharia de Dados, conectando conceitos técnicos à prática em um ambiente de desenvolvimento com Databricks e Claude Code.

## 🎯 Objetivo

Explorar o desenvolvimento de uma solução de Control Tower, utilizando dados e tecnologias modernas para apoiar a análise de informações e a construção de soluções inteligentes.

## 🛠️ Tecnologias e ferramentas

* *Python* — desenvolvimento e processamento de dados.
* *SQL* — consultas e manipulação de dados.
* *Databricks* — ambiente de desenvolvimento e processamento de dados.
* *Claude Code* — assistente de desenvolvimento com inteligência artificial.
* *Pytest ou outra ferramenta de testes* — a confirmar conforme as dependências do projeto.
